# Audit Events

Track and monitor system events and changes.

## List Audit Events

Retrieve a list of audit events.

```http
GET /audit-events
```

### Request

```bash
curl -X GET https://api.courier.com/audit-events \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Response

```json
{
  "events": [
    {
      "id": "event-123",
      "type": "message.sent",
      "timestamp": "2024-01-01T00:00:00Z",
      "user_id": "user-123",
      "details": {
        "message_id": "msg-123",
        "recipient": "user@example.com"
      }
    }
  ],
  "cursor": "next-page-token"
}
```

## Get Audit Event

Retrieve details of a specific audit event.

```http
GET /audit-events/{audit-event-id}
```

### Request

```bash
curl -X GET https://api.courier.com/audit-events/event-123 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Response

```json
{
  "id": "event-123",
  "type": "message.sent",
  "timestamp": "2024-01-01T00:00:00Z",
  "user_id": "user-123",
  "details": {
    "message_id": "msg-123",
    "recipient": "user@example.com"
  }
}
```

## Error Handling

The API may return the following error responses:

| Status Code | Description |
|-------------|-------------|
| 400 | Bad Request - The request was invalid or cannot be processed |
| 401 | Unauthorized - Invalid or missing API key |
| 404 | Not Found - The specified audit event does not exist |

## Best Practices

1. Use pagination when listing audit events
2. Store audit event IDs for future reference
3. Monitor audit events for security and compliance
4. Implement appropriate retention policies for audit logs

## Example Code

### Python

```python
import requests

def list_audit_events(api_key):
    headers = {
        "Authorization": f"Bearer {api_key}"
    }
    response = requests.get(
        "https://api.courier.com/audit-events",
        headers=headers
    )
    return response.json()

def get_audit_event(api_key, event_id):
    headers = {
        "Authorization": f"Bearer {api_key}"
    }
    response = requests.get(
        f"https://api.courier.com/audit-events/{event_id}",
        headers=headers
    )
    return response.json()
```

### JavaScript

```javascript
async function listAuditEvents(apiKey) {
  const response = await fetch('https://api.courier.com/audit-events', {
    headers: {
      'Authorization': `Bearer ${apiKey}`
    }
  });
  return response.json();
}

async function getAuditEvent(apiKey, eventId) {
  const response = await fetch(`https://api.courier.com/audit-events/${eventId}`, {
    headers: {
      'Authorization': `Bearer ${apiKey}`
    }
  });
  return response.json();
}
```
