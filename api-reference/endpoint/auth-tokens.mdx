# Authentication

Manage API authentication tokens.

## Issue Token

Create a new access token.

```http
POST /auth/issue-token
```

### Request

```bash
curl -X POST https://api.courier.com/auth/issue-token \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "scope": ["messages.send", "audiences.read"],
    "expires_in": 3600
  }'
```

### Response

```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "expires_at": "2024-01-01T01:00:00Z",
  "scope": ["messages.send", "audiences.read"]
}
```

## Error Handling

The API may return the following error responses:

| Status Code | Description |
|-------------|-------------|
| 400 | Bad Request - The request was invalid or cannot be processed |
| 401 | Unauthorized - Invalid credentials |
| 403 | Forbidden - Insufficient permissions |

## Best Practices

1. Store tokens securely and never expose them in client-side code
2. Use appropriate token expiration times
3. Implement token rotation for enhanced security
4. Monitor token usage and revoke compromised tokens
5. Use the principle of least privilege when assigning token scopes

## Security Considerations

1. Always use HTTPS for API requests
2. Implement proper token storage and management
3. Monitor and log token usage
4. Implement rate limiting for token issuance
5. Have a process for token revocation

## Example Code

### Python

```python
import requests

def issue_token(api_key, scope, expires_in=3600):
    headers = {
        "Authorization": f"Bearer {api_key}",
        "Content-Type": "application/json"
    }
    data = {
        "scope": scope,
        "expires_in": expires_in
    }
    response = requests.post(
        "https://api.courier.com/auth/issue-token",
        headers=headers,
        json=data
    )
    return response.json()
```

### JavaScript

```javascript
async function issueToken(apiKey, scope, expiresIn = 3600) {
  const response = await fetch('https://api.courier.com/auth/issue-token', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${apiKey}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      scope,
      expires_in: expiresIn
    })
  });
  return response.json();
}
```
